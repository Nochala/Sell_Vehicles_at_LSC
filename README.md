# Sell Vehicles at Los Santos Customs
![GTA V](https://img.shields.io/badge/Grand%20Theft%20Auto%20V-Legacy%20%7C%20Enhanced-2ea44f?style=flat&logo=rockstargames&logoColor=white) ![C++](https://img.shields.io/badge/Native-C%2B%2B-00599C?style=flat&logo=cplusplus&logoColor=white) ![GitHub Release](https://img.shields.io/github/v/release/Nochala/Sell_Vehicles_at_LSC?style=flat&label=Release)

### Brings GTA Online's native vehicle selling to ALL Los Santos Customs in GTA V Story Mode. 

#### Instead of recreating the Sell menu, this mod directly manipulates Rockstar's native Los Santos Customs scripts. 
#### Supports both Legacy & Enhanced.

**Fully compatible with both Legacy and Enhanced versions of GTA V.**
### Requirements:
- Latest [**ScriptHookV**](https://www.dev-c.com/gtav/scripthookv/)

### Features
- Adds the native GTA Online Sell option to Story Mode Los Santos Customs
- Supports GTA V Legacy and Enhanced
- Dynamic vehicle sell prices (Configurable via `.ini`)
- Installed upgrades affect vehicle value (Configurable via `.ini`)
- Optional vehicle damage penalty (Configurable via `.ini`)
- Optional vehicle sell cooldown (Configurable via `.ini`)
- Optional startup notification (Configurable via `.ini`)

### INSTALLATION 
- Install latest ScriptHookV.
- Place `SellVehiclesAtLSC.asi` & `SellVehiclesAtLSC.ini` into your root GTA V folder.
- Enjoy
